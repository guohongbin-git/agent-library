# Memory Log

This directory stores the agent's learning logs.

## Files

- `daily-report.md` - Auto-generated daily statistics
- `conversion-log.md` - Record of all PDF conversions

## Format

Each log entry follows the pattern:

```
## YYYY-MM-DD HH:MM

**Action**: [convert|search|update]
**Details**: ...

**Result**: [success|failure]
**Notes**: ...
```

---

*This directory is maintained by the Agent Library system.*
