# Input Files

Place your PDF files here for conversion.

## Supported Formats

- `.pdf` - PDF documents
- `.PDF` - (case insensitive)

## Processing

When you add a PDF:
1. The converter will parse it
2. Create semantic chunks
3. Generate TOON/Markdown/JSON outputs
4. Update the knowledge index

## Tips

- Use descriptive filenames
- One PDF per book/document
- Avoid password-protected PDFs
